# Life OS · web

Day Replay: карта дня + ползунок времени. Данные берёт с API на Самсунге через прокси Vite.

```bash
echo 'LIFEOS_TOKEN=...' > .env.local   # токен API, не коммитится
npm install
npm run dev                            # http://localhost:5173
```

Подробности об архитектуре — в `../CLAUDE.md`.
