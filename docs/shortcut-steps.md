# Шаги из Apple Health → Life OS (Быстрая команда на iPhone)

Как это работает: Быстрая команда берёт из «Здоровья» шаги **по часам** за последние 2 дня
и шлёт их на `POST /samples` (type `steps`). Один и тот же час можно слать сколько угодно раз —
значение просто обновится (текущий час iPhone досчитывает, это нормально).

Нужно: на айфоне включён **Tailscale** (как для Overland), токен API (тот же, что в `web/.env.local`).

## 1. Собрать команду «Life OS · шаги»

Приложение **Команды** → **+** → назови «Life OS · шаги». Действия по порядку:

1. **Найти образцы здоровья** (Find Health Samples)
   - Тип: **Шаги**
   - Фильтр: **Дата начала** → **за последние** → **2** → **дня**
   - **Группировать по**: **Час** (Group By: Hour)
   - Сортировка: Дата начала, по возрастанию; Ограничение — выкл.
2. **Повторить с каждым** (Repeat with Each) — по результату шага 1. Внутри повтора:
   1. **Текст**: три переменные через `;` без пробелов:
      `Повторяемый объект › Дата начала` `;` `Повторяемый объект › Дата окончания` `;` `Повторяемый объект › Значение`
      - у обеих дат нажми на переменную → **Формат даты: ISO 8601**, **Включить время ISO 8601: вкл.**
      - получится строка вида `2026-11-04T10:00:00+01:00;2026-11-04T11:00:00+01:00;612`
   2. **Добавить в переменную** → имя `строки`
3. *(после конца повтора)* **Объединить текст** → `строки`, разделитель **Новая строка**
4. **Получить содержимое URL** (Get Contents of URL)
   - URL: `http://100.119.158.113:3000/samples`
   - Метод: **POST**
   - Заголовки: `Authorization` = `Bearer ТВОЙ_ТОКЕН`
   - Тело запроса: **JSON**
     - `type` (Текст) = `steps`
     - `lines` (Текст) = результат шага 3 (**Объединённый текст**)
5. *(по желанию, для проверки)* **Показать результат** — должно быть `{"saved":…,"skipped":0}`

Первый запуск спросит доступ к «Здоровью» → разреши **Шаги**.

## 2. Запускать автоматически

**Команды** → **Автоматизация** → **+** → **Время суток**. Сделай несколько, например
**09:00, 13:00, 18:00, 23:30**, каждый день → **Запускать сразу** (без подтверждения) → команда «Life OS · шаги».
Пропущенный запуск не страшен: каждый раз уходят последние 2 дня целиком.

## Проверка

- В Life OS открой сегодняшний день — плитка **Шаги** перестанет быть «скоро».
- Или с ноута: `curl -H "Authorization: Bearer $TOKEN" "http://100.119.158.113:3000/samples?date=$(date +%F)"`

## Если не работает

| Что видно | Что делать |
|---|---|
| `{"error":"unauthorized"}` | токен в заголовке: `Bearer ` + токен, с пробелом |
| ошибка соединения / таймаут | Tailscale на айфоне включён? Самсунг «на связи» (плашка в шапке)? |
| `saved: 0, skipped: N` | даты не в ISO 8601 с временем, или разделитель не `;` |
| шаги в Life OS меньше, чем в «Здоровье» | «Здоровье» показывает за сегодня, а текущий час ещё досчитывается — дождись следующего запуска |
